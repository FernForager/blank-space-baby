# Codebase audit (Oct 29 and 30, 2026)

Morg's ask, at max effort: "a full code base audit." Five reviewers read the code from scratch, each with a fresh context and one area, and ran what they found in copies of the repo: the game's logic, its screens and text system, the server and deploys, the build and card tools, and the test tools. GM TRIVELLE checked every finding against the code before acting on it, fixed what was clearly a bug on `daily`, and lists the rest here. Nothing went to `main`: going live waits for Morg.

**In one line:** the live game works, and nobody had been hurt yet, but there were real holes: forged marks and text edits on the preview links, a service worker that deleted other apps' offline copies on the shared GitHub address, screen readers that read the answer aloud, duplicate results, a go-live check that could wave through a changed #1, and tests that could never fail.

## Needs Morg

1. **A sign-in in front of the preview links.** Anyone who finds a preview link can post flags, locks and text edits as if they were Morg's (the reviewer forged a lock that stopped the build, 299 flags that emptied the red column, and an edit that moved the share's link to another site). The code now holds suspicious ones for him, but the real fix is Cloudflare Access, a one-time switch: Cloudflare dashboard, **Workers & Pages**, the blank-space-baby project, **Settings**, **General**, **Enable access policy**. It covers every preview link, the beta included, and never triviela.net. Morg then signs in with his Cloudflare login now and then on the beta.
2. **Going live, with the first nine.** The fixes below change #1's wrong answers a little (they hold still from now on), so going live needs the save to move up a version, which gives every phone a fresh board. That's the same step the first nine need, so the two go live together once the fact check passes.
3. **Smaller calls** (Trivelle's pick in brackets): a per-board token in the results table, so a lost reply can never count a board twice (yes, a column added to the database), www.triviela.net sending players on to triviela.net, so one phone keeps one save (yes, a Cloudflare redirect rule), a proper layout for a phone turned sideways (later: it scrolls now, see below), the Home Screen app's status bar, white on cream today (yes: dark text), and a slimmer CLAUDE.md, with the history in its own file (yes: about half of its 26,000 tokens describe versions long gone, and every new session pays to read them).

## Fixed on the beta (`daily`)

**Server and deploys**
- The service worker deletes only its own caches (`bsb-`). It had been deleting every cache on fernforager.github.io, the grok-hiker copy's downloaded trails included (Peninsula Hiker itself lives at ophiker.com, its own address, so it was never touched, Scout says). A server error page now shows the saved game, and only the game's own page is kept offline. (Reaches GitHub Pages and triviela.net when `main` moves.)
- The endpoints refuse ids sent as lists (one crashed the text tool), and a result's nine cards must be nine different cards.
- Marks: a lock must name the card as it is now and an unlock the lock it lifts, or the sync holds it for Morg. Text edits: any edit to the game's name or address, or one adding a web address, waits for his OK.

**The game**
- Wrong answers hold still: each is ranked by its own hash, and near misses and the button order have their own streams, so a card in or out of a deck no longer moves other cards' choices (14 of 15 board cards held through two outs). The best same-kind pair wins before any other kind fills in, which ends two cards' surprise decoys.
- Spelled counts get spelled near misses: #1's Women's Euro card offered 354 and 48 for "eight", and now offers seven and ten. Year near misses follow the puzzle's own date, so a board's choices hold across New Year.
- One result per board: one post at a time, shared between tabs, and its answer lands on the day it belongs to. Two tabs on one day now stay in step instead of a stale tab wiping a finished day.
- Screen readers hear a meaning line only once it shows (VoiceOver read them before the answer: "Gary Lineker, six goals at Mexico 1986"), and the countdown isn't read out every second.
- A phone turned sideways, or a very short window, scrolls to the question instead of hiding it.
- Smaller: the slot rule counts answered cards, a day finished after its own midnight keeps its end screen, the text editor sets β and parentheses like the game, `?day=abc` and a missing canvas no longer blank the page, and the unused Yellowtail font isn't downloaded any more.

**Build and card tools**
- New checks: Morg's own wrong answers (`wr`) must be two different answers, neither the answer nor already on the card, in house style. Every deck needs a category, and every deck id the shape the services accept. A pin can't hold a red slang card. strings.py checks every id named in `th()` and `data-tid`, and refuses "soccer" or "football" in any string.
- A card with `wr` no longer has to join a kind, so adding one never sends its deck-mates back to the reviewers (it sent 34 back before).
- Flags and locks hold to the card's own fields (`mark_hash` in the build: its answer, sentence, means, hook, color, kind and Morg's own wrong answers), never to the wrong answers its deck-mates lend it, so a change elsewhere in the deck sends a card back to the reviewers but never lapses a flag or breaks a lock. The reviewers' verdicts keep the full fingerprint. (Fixed Oct 30, 2026, after the go-live: shown on a copy with a lock and a flag on cards without `wr`.)
- drawcheck.py replays every card's three choices on every day of a year and holds each wrong answer to the reviewers' own list (the build's `wrong_pool`, what `vet.py todo` shows them) or, on a number card, to a made-up near miss, so a playing card never shows a wrong answer nobody vetted (shown to fail with a word dropped from every list: 1,010 problems). The vetting tool now tells a reviewer when a card draws near misses and by what rule (`near_rule` in the build), so they judge whether a near miss could be a second right answer. Fixed Oct 30, 2026, after the go-live.
- vet.py won't take a locked card out. textedits.py applies only the newest batch (an edit Morg set back stays set back), and checks before it writes. results.py keeps different boards apart even when they share a number.

**Test tools**
- golive.py checks triviela.net really serves the build it compares, prints the build's switches, fails a build with the demo on, and no longer excuses a board that changes under its own number when one fixed board switches on or off. (Shown on a copy: it now fails where it used to pass.)
- lifecycle.py has a pass with real phone taps, so the tap shield is tested at last (shown to fail with the shield off).
- sweep.py fails on a problem on a board that plays (it never failed before), livecheck.py fetches `main` first, catches every `/api/` call, checks the demo is off and holds the post to the server's own rules.
- session-start.sh installs the Playwright whose Chromium the workspace preinstalled (the workspace's own playwright-core names the version), instead of a fixed pin that found no browser once the workspace moved on (1.63.0 and chromium-1243 on Oct 30, 2026, after 1.56.0 and chromium-1194). Fixed Oct 30, after the go-live.

## Open, for later

- **When the daily comes back:** results finished offline on one day and sent on a later one, the countdown's live region, and a board finished after midnight (fixed in part).
- **Phones the checks don't cover:** the 320-wide target is a 2× iPhone on iOS 15, where Bundesliga is cut off (tilecheck at 2× finds 65 cards) and container units don't exist (the GOLAZO! shout shrinks, the end screen's gap closes). Run the checks at 2× and give those rules a px fallback.
- **Screen readers:** the blank is silent, focus is lost when a card opens, and Review never says right or missed (needs one new spoken word, so Morg's OK).
- **Smaller:** textcheck never measures the smallest sentence size, drawcheck re-asks the page's own rules, a `schema.sql` would let the database be rebuilt, LEAGUE_MAX and WINDOW aren't passed from build.py, dead CSS and faux bold on four arcade-face slots, and CLAUDE.md's line on self-hosted fonts is out of date (this build uses Google Fonts).

## What held up

Card text, strings and URL parameters are all escaped. Every query is parameterized. Hostname gating is anchored and right on every address. The privacy promise holds (no name, device or IP stored). A year of draws keeps every guardrail. All 1,487 cards render one blank with three different choices. Old and corrupt saves start fresh. The build is byte-identical across runs.
